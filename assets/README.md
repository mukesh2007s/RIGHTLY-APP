# Rightly Assets

This folder contains application assets.

## Structure

- `images/` - App images and illustrations
- `icons/` - App icons
- `animations/` - Lottie animation files
- `data/` - Legal data JSON files
- `fonts/` - Custom fonts (Inter, Poppins)

## Note

Fonts will be loaded from Google Fonts package.
Add your app icon to `icons/app_icon.png` for launcher icon generation.
